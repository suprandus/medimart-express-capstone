# MediMart Express

**MediMart Express** is a sleek and efficient e-commerce platform designed to simplify the purchase of medical supplies and healthcare products. Built with modern web technologies, it delivers a seamless experience for both vendors and consumers in the medical industry.

## Tech Stack
- **Backend**: Laravel
- **Frontend**: Bootstrap 4, JavaScript, jQuery
- **Database**: MySQL

## Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/suprandus/medimart-express-capstone.git
cd medimart-express-capstone
composer install
npm install
```
